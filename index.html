To export and save data:
  1. Open DHI Sales in your browser
  2. Open DevTools (F12) → Console tab
  3. Paste this code and press Enter: 
    fetch('https://homesales.drhorton.com/Inventory/Home/GetInventorySearch?businessUnit=75%7CDivision&MonthlyPayment=0&PercentOfTolerance=0&filterData=false&_=' + Date.now())
  .then(r => r.json())
  .then(data => {
    const blob = new Blob([JSON.stringify(data, null, 2)], {type: 'application/json'});
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'drhorton-inventory.json';
    a.click();
  });
  4. File downloads automatically - then upload it here

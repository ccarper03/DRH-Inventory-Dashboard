Pull Inventory Data

How to use:

  1. Open DR Horton Homes Sales in your browser
  2. Open Developer Tools (F12 or Cmd+Option+I)
  3. Go to the Console tab
  4. Paste the script below and press Enter
  5. The JSON file will automatically download
  6. Return here and click "Load JSON" to upload the downloaded file
fetch('https://homesales.drhorton.com/Inventory/Home/GetInventorySearch?businessUnit=75%7CDivision&MonthlyPayment=0&PercentOfTolerance=0&filterData=false&_=' + Date.now()) .then(r => r.json()) .then(data => { const blob = new Blob([JSON.stringify(data, null, 2)], {type: 'application/json'}); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = 'drhorton-inventory.json'; a.click(); });
